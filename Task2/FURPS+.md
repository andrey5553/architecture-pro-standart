| Код | Требования                                                                                           | Комментарий  |
|-----|------------------------------------------------------------------------------------------------------|--------------|
| F   | **Функциональные (Functionality)**                                                                   |              |
|     | - Возможность просмотра списка депозитов с актуальными ставками для новых и существующих клиентов.   |              |
|     | - Возможность подачи заявки на депозит через сайт (ФИО, номер телефона) и интернет-банк.             |              |
|     | - Возможность просмотра списка доступных кредитов для новых и существующих клиентов (предодобрение). |              |
|     | - Возможность подачи заявки на кредит через сайт (ФИО, номер телефона) и интернет-банк.              |              |
|     | - Обработка заявки менеджером кол-центра (для новых клиентов) и бэк-офисом (для существующих).       |              |
|     | - Поддержка особых условий депозитов/кредитов.                                                       |              |
|     | - SMS-уведомления на ключевых этапах (подтверждение ставки, открытие депозита/кредита).              |              |
|     | - Хранение и управление ставками по депозитам/кредитам (интеграция с XLS → переход в АБС).           |              |
|     | - Защита передаваемых данных (шифрование трафика).                                                   |              |
| U   | **Удобство использования (Usability)**                                                               |              |
|     | - Интерфейс соответствует корпоративному дизайну (цвета, брендинг).                                  |              |
|     | - Минимальное время отклика.                                                                         |              |
|     | - Минимум шагов по заполнению формы, интуитивно-понятные вопросы.                                    |              |
|     | - Служба поддержки сайта и мобильных устройств.                                                      |              |
| R   | **Надёжность (Reliability)**                                                                         |              |
|     | - Доступность в любое время суток.                                                                   |              |
|     | - Отказоустойчивость (переключение на резервный ЦОД при сбое).                                       |              |
|     | - Горизонтальное масштабирование интернет-банка.                                                     |              |
|     | - Вертикальное масштабирование АБС.                                                                  |              |
|     | - Защита от перегрузки АБС (избегать прямых вызовов API, использовать очереди или брокер сообщений). |              |
|     | - Мониторинг и алертинг при сбоях.                                                                   |              |
| P   | **Производительность (Performance)**                                                                 |              |
|     | - Быстрая загрузка справочных данных (<1 сек).                                                       |              |
|     | - Оптимизация запросов к БД (кеширование, индексы).                                                  |              |
|     | - Распределение нагрузки между серверами и ЦОД.                                                      |              |
|     | - Минимизация задержек при работе с АБС (асинхронные вызовы, очереди).                               |              |
| S   | **Поддерживаемость (Supportability)**                                                                |              |
|     | - Использование существующих технологий (MS SQL, Oracle).                                            |              |
|     | - Использование популярных и подходящих ЯП и фреймворков.                                            |              |
|     | - Постепенный переход на микросервисы (в рамках депозитов).                                          |              |
|     | - Документация для дальнейшего расширения системы.                                                   |              |
| +R  | **+ Ограничения (Restrictions)**                                                                     |              |
|     | - Шифрование трафика (TLS для сайта и интернет-банка).                                               |              |
|     | - Защита персональных данных (номер телефона, ФИО).                                                  |              |
|     | - SMS-подтверждение при аутентификации/авторизации.                                                  |              |
|     | - Аудит действий работников банка и клиентов (логирование, сохранение истории действий)              |              |
|     | - Интеграция с кол-центром и АБС.                                                                    |              |
|     | - Минимизация доработок ядра (SMS-функционал силами банка).                                          |              |
|     | - Постепенное развертывание (MVP с ручной обработкой заявок).                                        |              |
|     | - Совместимость с текущей инфраструктурой.                                                           |              |
|     | - Ограничения АБС (перегруженная БД, вертикальное масштабирование).                                  |              |
